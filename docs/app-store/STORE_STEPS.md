# 앱 스토어 등록 절차 (Google Play + App Store)

> 한 STEP씩 진행한다. 각 STEP: 계획 → 확정 → 작업 → 확인 → ✅ 표시. 다음 STEP으로 자동 진행하지 않는다.
> 담당: 🙋 사용자(콘솔·계정 작업) / 🤖 Claude(코드·문구·점검)
> 보류: 푸시 알림 → 다음 업데이트(v1.1). 바코드 스캔·신고/차단·계정 삭제를 앱 기능으로 내세운다(애플 4.2 대비).

## 공통 준비
- ✅ STEP 0. iOS 껍데기(Capacitor) + Codemagic 설정 — 커밋 f9c3ff1, `docs/app-store/ios-build-guide.md`
- ☐ STEP 1. 🙋 심사 로그인 준비 — **두 스토어 모두 심사자가 로그인할 수 있어야 함** (2026.11.04 확정: 카카오 심사 계정 대신 애플·구글 계정)
  - STEP I3로 애플·구글 로그인이 배포된 뒤 진행
  - Google Play: 심사 전용 Gmail 1개(본인 계정 사용 금지, 2단계 인증 끄기) → 구글 로그인으로 가입·닉네임·아이 1명·기록 1~2건 → 계정 정보를 '앱 액세스'에 적는다
  - App Store: 심사 메모에 'Apple로 로그인' 사용을 안내한다. ⚠️ 심사자 본인 Apple ID 사용이 통과된다는 공식 근거는 없음 — 2.1(a)로 거절되면 심사 전용 로그인을 추가해 대응
- ☐ STEP 2. 🤖 스토어 자료 점검 — 스크린샷·그래픽·아이콘·설명문(`앱스토어/업로드용`, `앱스토어/플레이 스토어 패키지`)
  - ⚠️ 서명 키(.jks/.keystore)·비밀번호는 저장소에 올리지 말 것(.gitignore 처리됨). 키는 따로 백업.

## Google Play (Android, TWA)
- ☐ STEP A1. 🙋 개발자 계정 검토 완료 대기 (진행 중)
- ☐ STEP A2. 🙋+🤖 Play Console 앱 만들기 + '앱 콘텐츠' 작성 (🤖 답변 초안)
  - 개인정보처리방침 URL: https://bookgardening.co.kr/privacy
  - 앱 액세스: STEP 1 심사 전용 Gmail 계정(구글 로그인 안내 포함)
  - 광고: 없음 / 콘텐츠 등급 설문 / **타겟층: 18세 이상(양육자)** — 아동 포함 시 가족 정책 적용되니 주의
  - 데이터 보안 양식 / 계정 삭제 URL: https://bookgardening.co.kr/account-deletion
  - 스토어 등록정보: 앱 이름·짧은 설명(80자)·자세한 설명(4000자)·스크린샷·그래픽 이미지 1024×500·아이콘 512
- ☐ STEP A3. 🙋 **비공개 테스트** 트랙에 AAB 업로드 → 테스터 12명 이상(15명 확보)이 **14일 연속** 참여
  - 테스터에게 '참여' 링크 수락 + 실제 설치·사용 요청
- ☐ STEP A4. 🙋 프로덕션 출시 신청(14일 후, 설문 답변 🤖 초안) → 심사(보통 수일)

## App Store (iOS)
- ✅ STEP I1. 🙋 App Store Connect: App ID(`kr.co.bookgardening.app`, Sign In with Apple 체크) + 앱 생성 + API 키(.p8)
- ☐ STEP I2. 🙋 Codemagic 연결 → 첫 TestFlight 빌드 → 아이패드에서 확인 (🤖 빌드 오류 대응)
- ☐ STEP I3. 🤖 로그인 수단 추가 + 🙋 Apple·Google 키·Supabase 설정 (가이드라인 4.8)
  - 확정(2026.11.04):
    · 카카오 = 모든 곳, 큰 기본 버튼(주력)
    · 애플 = **iOS 앱에서만**, 기본 로그인 창(Capacitor 플러그인 → Supabase signInWithIdToken). 웹용 A는 필요 시 추가(같은 계정 이어짐)
    · 구글 = **Android 앱(TWA)·일반 브라우저만**. iOS 앱 웹뷰·카톡 등 인앱 브라우저에선 숨김(구글이 웹뷰 로그인 차단 disallowed_useragent)
    · '지난번에 ○○로 로그인했어요' 표시 — 계정 쪼개짐 방지(이메일 미수집이라 자동 병합 불가)
  - DB: users.kakao_id 필수 해제 + 로그인 수단 열(hide_kakao_id.sql grant 목록도), 탈퇴 시 카카오 연결끊기는 카카오 가입자만 + 애플 토큰 취소
  - 약관·개인정보처리방침 '로그인 수단' 문구 갱신(CLAUDE.md 13.1 법률 문서 연동)
- ☐ STEP I4. 🙋 새 빌드 → TestFlight 실기기 점검(로그인 2종·바코드·사진·바깥 링크·탈퇴)
- ☐ STEP I5. 🤖 스토어 정보 초안 + 🙋 입력
  - 스크린샷 iPhone 6.9인치(1320×2868 또는 1290×2796) 3~10장 — Mac/아이폰 없으면 🤖 사이트 화면을 해당 크기로 캡처해 생성 가능
  - 설명·키워드(100자)·지원 URL·개인정보처리방침 URL·**앱 개인정보(데이터 수집 라벨)**·연령 등급
  - 심사 메모: 'Apple로 로그인' 사용 안내, 바코드 스캔, 신고·차단, 앱 내 계정 삭제 위치
- ☐ STEP I6. 🙋 심사 제출 → 거절 시 🤖 사유 대응
