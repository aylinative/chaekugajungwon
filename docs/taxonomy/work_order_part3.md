## 확정된 원칙

1. 모든 태그는 작성자가 입력할 때 직접 고른 것만 저장함. **기존 기록에 새 태그를 소급해서 달지 않음**
2. 고를 수 있는 개수는 **상한 없음**
3. 추천 주제, 다른 양육자의 선택은 **미리 선택된 상태로 두지 않음.** 사용자가 직접 눌러야 저장됨
4. 다른 양육자의 선택은 **사용자가 하나 이상 고른 뒤에만** 보여줌. 인원수는 표시하지 않음
5. 표시 규칙: 기록하기 화면의 고르는 칩에는 `#`을 붙이지 않고, 책 상세와 카드에 보여주는 태그에는 `#`을 붙임
6. 지우기: 화면에 보이는 칩 하나가 지우는 단위. 1번 입력, 1번 취소

## 1. DB 구조 요구사항
기존 테이블을 최대한 살리고, 새로 만들기보다 컬럼 추가를 우선해줘.

큰 분류
- 10개. id(slug), 이름, 정렬 순서
- 지금 코드에 하드코딩되어 있다면 DB로 옮길지, 상수 파일로 둘지 장단점과 함께 제안해줘

태그 (주제와 세부를 같은 테이블에)
- slug: aliases_v1.csv의 태그ID
- 큰 분류 연결
- parent: 세부일 때 상위 주제
- level: 'topic' | 'detail'
- sub_required: 세부를 반드시 골라야 하는 주제 (상상·판타지만 true)
- sort_order
- chip_example: 칩 아래 회색 예시 문구
- search_aliases: 검색 별칭 (배열)
- intro_keywords: 책 소개 매칭어 (배열)
- intro_excludes: 소개 제외어 (배열)
- is_active: 기존 컬럼 유지 (false = 새 기록에서 고를 수 없음)

게시물-태그 연결
- source 컬럼 추가: 'recommend' | 'others' | 'all' | 'legacy'
  (추천 주제 / 다른 양육자 줄 / 주제 더보기 시트 / 개편 전 기록)
  운영자만 보는 값. 화면에는 표시하지 않음

## 2. 마이그레이션 요구사항 (mapping_v1.csv의 처리방식별)
- 그대로: 변경 없음, 큰 분류만 연결
- 이름변경: 기존 태그 행의 이름·slug만 바꿈 (게시물 연결 유지)
- 이동: 큰 분류만 바꿈
- 세부로 이동: 이름변경 + parent 연결 + level='detail'
- 통합: 게시물 연결을 대상 태그로 옮기고 원래 태그는 is_active=false
- 보존(큰분류 연결): is_active=false, 큰 분류만 연결. 게시물 연결 유지
- 보존(분류 밖): is_active=false, 큰 분류 없음. 게시물 연결 유지
- 매핑표에 없는 새 태그: aliases_v1.csv 기준으로 새로 생성
- 기존 게시물-태그의 source는 모두 'legacy'
- 전체를 하나의 트랜잭션으로. 실패하면 전부 되돌아가게

## 3. 필터 규칙
- 주제로 필터: 그 주제가 달린 기록 + 그 주제의 세부가 달린 기록
  (개편 전 '과일'처럼 세부만 달린 기록도 '음식'에서 보여야 함)
- 큰 분류로 필터: 그 큰 분류에 연결된 모든 태그가 달린 기록 (is_active=false 포함)
  (개편 전 '동물'은 '동물' 큰 분류 필터에서 계속 보여야 함)
- 세부로 필터: 그 세부가 달린 기록만

## 4. 저장 규칙
- 세부를 고르면 주제와 세부를 둘 다 저장
- 상상·판타지는 세부를 하나 이상 골라야 저장됨

## 1. 영역 구성 (위에서 아래 순서)

[제목 줄]
- 왼쪽: "주제 태그" + 작은 회색 "선택"
- 오른쪽: "주제 더보기 ›" 텍스트 버튼 → 전체 주제 시트 열기
- 기존 (i) 아이콘과 툴팁은 제거

[설명 한 줄, 전체 폭]
- "내가 고른 주제는 다른 양육자가 책을 찾을 때 도움이 돼요"

[고른 주제 요약] (하나라도 골랐을 때만)
- 연한 올리브 배경 박스 안에 칩 나열, 각 칩에 × 버튼
- 세부가 있는 칩은 두 줄: 위에 주제(11px 회색), 아래에 세부(굵게)
- ×는 그 칩 하나를 지움.
  - '하늘·우주 › 달'의 ×: 달과 하늘·우주를 함께 지움
  - 같은 주제의 세부가 여러 개면 그 세부만 지우고, 마지막 세부가 빠질 때 주제도 함께 지움
- 각 칩에 aria-label: "하늘·우주 달 빼기" 형식

[추천 주제] 칩 8개, 여러 줄로 줄바꿈
- 앞자리: 책 소개 매칭 결과 (최대 4개, 아래 3번 참고)
- 남은 자리: 자주 쓰는 주제 (아래 4번 참고). 매칭 결과와 같은 주제는 건너뜀
- 세부까지 매칭된 칩은 두 줄 표기 (위: 주제, 아래: 세부)
- 칩을 누르면 선택/해제. 세부 칩은 주제+세부를 한 번에 선택/해제
- 모든 칩 높이 44px로 통일

[세부 박스] 회색 박스, 한 번에 하나만
- 마지막으로 고른 주제가 세부를 가진 주제면 그 주제의 세부 칩을 보여줌
- 세부가 없는 주제를 고르면 박스를 닫음
- 박스 안 세부 칩을 누르면 박스는 열린 채로 유지
- 박스가 열린 주제를 해제하면 박스 닫음
- 문구: "{주제} · 더 자세히 고를 수 있어요 (선택)"

[다른 양육자들은 이런 주제도 골랐어요] (조건부)

- 인원수 표시 없음. 순서는 많이 고른 순
- 한 줄 가로 스크롤, 점선 테두리 칩 + 앞에 + 아이콘
- 보조 문구: "놓친 게 있다면 더해주세요"
- 숨김 처리된 기록(hidden_at)과 내 기록은 제외

## 2. 전체 주제 시트 (주제 더보기)

  - 세부가 있는 카드에 작은 표시: "세부 선택 가능" / 상상·판타지는 "세부 선택 필요"

## 1. 책 상세·카드의 태그 표시
- 태그 앞에 '#'
- 세부가 있으면 세부 이름으로 표시 ('#달', '#잠'). 세부 이름은 모두 서로 달라서 겹치지 않음
- 세부와 그 주제가 함께 저장된 경우 주제는 생략하고 세부만 표시
- is_active=false인 개편 전 태그도 그 기록에는 그대로 표시

## 2. 홈 필터
- 기존 카테고리 탭 6개를 큰 분류 10개로 교체 (가로 스크롤 탭 패턴 유지)
- 큰 분류 탭 → 그 안의 주제 칩 → (세부가 있는 주제면) 세부 칩
- 필터 규칙은 Step 1의 3번을 따름
- 큰 분류 탭만 고른 상태에서는 그 큰 분류 전체 결과를 보여줌

## 3. 홈 검색
- Part 0에서 보고한 현재 검색 방식은 유지
- 추가: 검색어가 어떤 태그의 search_aliases와 정확히 같거나 앞부분이 같으면
  그 태그가 달린 책도 결과에 함께 보여줌
- 책 제목 결과와 태그 결과를 섞지 말고, 제목 결과 아래에 "주제로 찾은 책" 묶음으로
- 별칭 비교는 브라우저에 불러온 태그 데이터로 (추가 서버 호출 없음)

## 4. 운영자 주제 태그 관리 화면
- 큰 분류 → 주제 → 세부 계층으로 표시
- 각 태그에서 수정 가능: 이름, chip_example, search_aliases, intro_keywords, intro_excludes, 정렬, 숨김
- 숨김은 삭제가 아님. 기존 기록 연결은 유지
- 출처 통계: 최근 30일 저장된 태그 중 recommend / others / all 비율
  (others 비율이 지나치게 높으면 쏠림 신호)
